This repository showcases hands-on cloud engineering work covering:

- Infrastructure as Code using Terraform
- AWS cloud architecture and service integration
- CI/CD pipeline implementation
- Compute, networking, storage, and database provisioning
- Secure IAM and access control configuration
- Monitoring, logging, and operational readiness
- Deployment automation for cloud-native applications

The goal of this repository is to demonstrate the ability to build scalable, secure, and maintainable cloud infrastructure aligned with real-world engineering standards.
